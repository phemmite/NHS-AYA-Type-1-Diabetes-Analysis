#  NHS AYA Type 1 Diabetes Analysis

##  Project Overview
This project analyzes healthcare data from the National Health Service (NHS), focusing on the Adolescent and Young Adult (AYA) Type 1 Diabetes Audit.
The goal is to explore treatment outcomes, identify trends, and evaluate healthcare performance for young people aged 15–25 living with Type 1 diabetes.

---

##  Objectives
- Analyze HbA1c outcomes across age groups
- Identify trends in diabetes management over time
- Evaluate differences in healthcare performance
- Generate insights to improve patient outcomes

---

##  Dataset
- Source: NHS (National Health Service)
- Dataset: AYA Type 1 Diabetes Audit
- Data includes:
  - Age group
  - Treatment outcomes (HbA1c)
  - Patient metrics
  - Time period data

---

##  Data Cleaning Process
- Removed missing values from key columns
- Converted "Value" column to numeric format
- Standardized column names
- Filtered dataset for relevant measures (HbA1c)

---

##  Analysis Performed
- Average HbA1c by age group
- Trend analysis over time
- Comparison of treatment outcomes

---

##  Key Insights
- HbA1c levels vary significantly across age groups
- Younger adults tend to have less stable diabetes control
- Trends suggest inconsistencies in treatment outcomes over time

---

##  Recommendations
- Improve transition care for young adults
- Increase monitoring for high-risk groups
- Enhance patient education and support systems
